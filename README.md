# Talaria Dynamics

Static site for Talaria Dynamics and the Manta Wing.

- `index.html`: the whole page (styles and scripts inline; Three.js loads from jsDelivr).
- `final.js`: the Manta Wing 3D model (GLB, base64-encoded as an ES module).

Netlify: no build command; publish directory is the repo root (set in `netlify.toml`).
